Нормативы ВФСК ГТО для школьников с 1 по 11 класс. В каждой таблице испытания пронумерованы и сгруппированы по физическим качествам: скорость, выносливость, сила, гибкость, скоростно-силовые качества и прикладные навыки. Сначала идут обязательные испытания, затем — испытания по выбору. В конце каждой таблицы указано, сколько испытаний нужно выполнить для получения знака отличия. Значения приведены по таблицам нормативов ГТО 2025 года.
